Kniha jázd: UI mockups

Each page of the app as frames, one frame per screen state, with notes under each frame. The example data is invented. The UI text is Slovak, as in the app.

A change that the user will see is drawn here first, marked "Návrh (task NN)", before the code. The files are in docs/mockups/ of the repo.

PC

Jazdy/The trip logbook: the app header, the vehicle and year stats, the trip grid, the row editor, the odometer shift and the print export. Doklady/dokladyThe Paperless-ngx invoices of the year, and the dialog that assigns an invoice to a trip. Fuelio/fuelioThe GPS drives of the Fuelio app next to the logbook: the cross-check table, the map, and the dialogs to overwrite or add a trip. Mapa/mapa?trip=<id>The route map of one trip: direct, round trip and loop routes, the alternatives, and the distance write-back. Miesta/miestaThe place book: add, rename, set the position on the map, set the home place, delete. Nastavenia/settingsThe settings: preferences, Home Assistant, Paperless-ngx, the vehicles, the company, and the database backups.

Phone

Mobil/mThe phone pages: the start page, the trip list and detail, add a trip from Fuelio or by hand, and the route choice.
The registry of the mockups and the workflow are in docs/mockups/README.md in the repo.
