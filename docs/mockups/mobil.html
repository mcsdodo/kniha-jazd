Kniha jázd on the phone: current state

Nine phone screens under /m, as they work on main. The example data is invented. The UI text is Slovak, as in the app. The notes under each screen say what the screen does.

The source is docs/mockups/mobil.html in the repo. Its git history shows when the page changed.

An orange dashed box with the tag "Návrh (task NN)" marks a proposal that is not built yet. This page has no open proposal.

Uložiť jazdu
  • "Odkiaľ" and "Kam" use the same picker: an existing place or a new place.
  • "Odkiaľ" starts with the destination of the last trip before the end time. The backend picks it.
  • "Kam" reads the GPS when the page opens. "Moja poloha" sorts the list by distance and selects a known place near the point (BIZ-031). No such place: a new place at the GPS point opens.
  • "Koniec" starts at now. You can set another time, and "Teraz" sets now again.
  • When both places have a position, the backend computes the route. It fills "Začiatok" (the end minus the drive time) and the km (rounded to whole km). A value that you type stays.
  • No fuel fields.
  • The OSRM / Sygic switch (no title) shows only when the server has 2 or more providers (a Sygic key is set). It starts at the server default (OSRM). A change asks for the route again and selects route 1. The choice is not remembered.
  • The map (200 px) shows the chosen route in blue and the other alternatives in grey. Pinch and drag work, as on the trip detail.
  • The chips list the alternatives, fastest first, in the order the backend sends them, at most 3. With one route there are no chips and the line says "Podľa trasy: ...". See screen 9 for a tap on route 2.
  • A new end time keeps the chosen route. If the route fails, the map and the chips hide, and you type the start and the km.

Uložiť jazdu
  • A tap on the chip "2" or on the grey line selects route 2. The map swaps the colours, and the map does not zoom again.
  • "Začiatok" and the km take the values of route 2: 15:30 - 38 min = 14:52, and 21.2 km rounded to 21. The backend computes both (ADR-008). A value that you typed stays.
  • "Uložiť jazdu" saves the trip, then the chosen route (command save_manual_trip_route, a second write after the trip commit). The trip detail (screen 3) then shows this route.
  • The stored route keeps the trip km as its target, so a typed km shows as a deviation on the map, as on /mapa.
  • If the trip saves but the route does not, the trip stays and a message says that the route was not saved, as on the Fuelio add page.
  • The "avoid paid roads" checkboxes of a Sygic route stay on the PC /mapa page.
