Kniha jázd on the PC: Mapa (current state)

The route map of one trip at /mapa?trip=<id>, opened from the map pin of the trip grid in a new tab, as it works on main. The example data is invented. The UI text is Slovak, as in the app. The notes under each frame say what the screen does.

The source is docs/mockups/mapa.html in the repo. Its git history shows when the page changed.

An orange dashed box with the tag "Návrh (task NN)" marks a proposal that is not built yet. This page has no open proposal.

  • The map pin of a trip row opens this page in a new tab. The page uses the app header (frame 1 of Jazdy). No nav item is marked: the nav has no "Mapa" link.
  • At load the page reads all trips of the active vehicle (get_trips) and finds the trip by id. Then it reads the saved map (get_trip_route). With no saved map it asks for the mode and the endpoints (start_route_for_trip).
  • The backend picks the mode. The same place in "Odkiaľ" and "Kam" gives a loop (frame 5). Two places give a direct route. The endpoints come from the place book, not from a geocode.
  • The line next to the title comes from the trip: the origin, the destination and the trip km.
  • "Smerovanie:" shows only when the server offers two providers, that is with SYGIC_API_KEY set (get_route_providers). The default is OSRM, also with the key (ADR-053). A change routes a direct trip again at once.
  • A direct route goes to route_direct with the trip km as the target. The backend returns up to 3 alternatives in the order of the routing service (fastest first).
  • "Prepočítať" routes the current point list again. It saves nothing. While a request runs, the button and the status line read "Generujem trasu...".
  • "Cieľová vzdialenosť" is the trip km. "Skutočná vzdialenosť" is the road km of the active line. The backend computes "Odchýlka". It turns orange (not red) when the route is outside the backend tolerance (TOLERANCE).
  • Each alternative button shows the km, the drive time ("Čas jazdy") and the deviation. A click on a button or on a grey line makes it active. This sends no request and the map does not zoom.
  • "Uložiť a použiť vzdialenosť" is enabled for an unsaved proposal, or for a saved map whose km does not match the trip. Frame 7 shows what it writes. "Odstrániť mapu" shows only with a saved map (frame 2).
  • "Zastávky (n)" always lists every point. The edit hint always shows. The A pin (green) is the start, the B pin (red) is the end. Their tooltips are "Začiatok trasy" / "Koniec trasy" with the place name.
  • A drag of a pin routes again once, on release. A drag on the blue line adds a via (frame 4).
  • A saved one-way map that opens again shows no alternatives: the row stores only the chosen line. "Prepočítať" gets them again.

  • "Cesta tam a späť" shows only in direct mode. A tick routes the way out and the way back as two requests (route_round_trip), so the way back can use a different road.
  • The trip km is the target of the whole round trip. "Skutočná vzdialenosť" and "Odchýlka" are the backend sum of the chosen pair.
  • The way out is blue (#0066cc), the way back is amber (#d97706). The other alternatives of each leg are grey (#94a3b8) and can be clicked.
  • Each leg has its own list: "Alternatívne trasy - Tam" and "Alternatívne trasy - Späť". The two choices are independent. A leg button shows the km and the drive time, but no deviation.
  • Only the way out has pins: A at the start and B at the turnaround. The way back shares those points, so it draws no pins of its own.
  • A via on one leg stays on that leg. A leg with a via shows "Alternatívy nie sú dostupné, keď trasa vedie cez viac ako dva body." in place of its list.
  • The box state is saved with the map. A saved round trip opens with the box ticked and both legs drawn from the saved row. The leg lists stay empty until "Prepočítať".
  • The save sends save_trip_round_trip_route with the chosen alternative of each leg. The backend joins the legs and sums the km.

+-
Leaflet | © OpenStreetMap contributors
  • Loop mode applies when "Odkiaľ" and "Kam" are the same place. The loop starts and ends at that place, so the place needs a position (frame 6).
  • The page generates a loop at once (generate_route). "Km okruhu:" is the target and starts at the trip km. Empty or 0 uses the trip km.
  • "Zastávky:" is "Auto" or a fixed count 1 to 10. With "Auto" the generator picks 1 to 5.
  • A change of "Km okruhu:" or "Zastávky:" and "Generovať znova" each draw a new random loop. A change of "Smerovanie:" does not: it applies to the next generation.
  • Loop mode has no alternatives, no "Cesta tam a späť" and no avoid boxes. "Odchýlka" turns orange outside the same tolerance.
  • One green A pin marks the start and the end ("Začiatok a koniec okruhu"). The vias are numbered blue circles. A drag or a click edits the loop, and it stays a loop (route_direct with the closing leg).
  • "Uložiť a použiť vzdialenosť" writes the km of the drawn loop to the trip, not the typed target.
  • A place outside every candidate area fails with "Pre toto miesto generátor nemá kandidátov." (no retry). Other failures show "Trasu sa nepodarilo vygenerovať" with "Skúsiť znova".

ZrušiťUložiť miesto
  • An endpoint place from an old database can have no position. start_route_for_trip then returns no endpoint, and the page opens the place dialog at once. The origin comes first, then the destination.
  • The search field holds the place name. The search runs only on "Hľadať" or Enter (geocode_place), never on a key press: the geocoder allows one request per second.
  • A click on a result moves the pin there. A click on the map or a drag of the pin places it by hand. The page keeps only the position, not the result text: the place keeps the name that the trips use.
  • The other states: "Hľadám...", "Nič sa nenašlo. Umiestnite špendlík na mape ručne.", "Vyhľadávanie zlyhalo. Skúste to znova.".
  • "Uložiť miesto" is disabled until a pin exists. The dialog writes nothing itself. The page saves the position (set_place_position), shows the toast "Miesto uložené", and routes at once.
  • If the write fails (for example in read-only mode), the toast "Nepodarilo sa uložiť miesto: ..." shows and the dialog stays open with its pin.
  • "Zrušiť", the close button, Esc or a click outside close the dialog. Then the red banner stays, and "Umiestniť miesto" opens the dialog again. "Prepočítať", the round-trip box and the save stay disabled.
  • The banner shows in direct mode only. A loop with an unplaced start gets the dialog, but no banner (see the open points).

  • The button first sends a dry run of the save: save_trip_route (one-way or loop), save_trip_round_trip_route (round trip), or apply_saved_route_distance (a saved map out of sync). The dry run writes nothing.
  • The backend rounds the road km to whole km (52.4 -> 52). The map keeps the exact road km. Only the trip km is rounded.
  • If the rounded km equals the trip km, the page saves at once with no dialog. If not, this dialog shows the plan.

  • Closed period: "Spotreba obdobia: ... -> ..." and "Odchýlka od TP: ... -> ...". Then one of three lines: "Pozor: po zápise obdobie prekročí zákonný limit 20 %." With no later trip the dialog says "Žiadna nasledujúca jazda sa neposunie.". The line "+N km -- vaša zmena vzdialenosti" shows in both cases.

  • "Zapísať vzdialenosť" sends the same call as at the click, now not as a dry run. The backend plans again from the stored book and writes the map, the trip km, the trip odometer and the shifts in one transaction.
  • "Zrušiť", Esc or a click outside close the dialog and write nothing. A failed plan or save shows the toast "Trasu a vzdialenosť sa nepodarilo uložiť".

  • After a save the green notice shows, with the toast "Trasa uložená, vzdialenosť jazdy zodpovedá mape". "Zavrieť" closes the browser tab. The next routing run hides the notice.
  • A save tells an open logbook tab about the change (BroadcastChannel kniha-jazd), so its map pin and its km update. After the save "Uložiť a použiť vzdialenosť" is disabled until the next change.
  • The red box with "Skúsiť znova" is a failure that a retry can fix: "Trasu sa nepodarilo vypočítať" (direct, round trip) or "Trasu sa nepodarilo vygenerovať" (load, loop). A failure drops the proposal, so nothing stale can be saved.
  • The red box without a button is a failure that a retry cannot fix: "Záznam sa nenašiel. Skontrolujte, či máte vybrané správne vozidlo.", "Jazda nemá vyplnené miesto odchodu alebo príchodu.", "Služba Sygic nie je na serveri nastavená. Vyberte OSRM.", "Vyhnúť sa spoplatneným cestám sa dá len so službou Sygic. ...", "Pre toto miesto generátor nemá kandidátov.".
  • "Záznam sa nenašiel..." shows when the trip id is not a trip of the active vehicle.
  • While the page loads or routes, the status line "Načítavam..." or "Generujem trasu..." replaces the route info. All buttons are disabled.

Naozaj odstrániť mapu trasy?

ZrušiťOdstrániť
  • "Odstrániť" deletes the saved map (delete_trip_route). It does not change the trip km. The toast "Mapa trasy odstránená" shows, and the logbook tab clears its map pin.
  • An unsaved proposal on screen stays. With no proposal the map is empty until "Prepočítať" or "Generovať znova".
  • A failed delete shows the toast "Trasu sa nepodarilo vygenerovať" (see the open points).

Open points (from the code, not fixed)

  • A failed delete shows the generation text "Trasu sa nepodarilo vygenerovať" (routeMap.error), not a delete text (src/routes/mapa/+page.svelte:1487).
  • The "Umiestniť miesto" banner shows in direct mode only (src/routes/mapa/+page.svelte:305). In loop mode with an unplaced start, a closed place dialog leaves no way to open it again, except a page reload. "Generovať znova" stays enabled.
  • The page has no read-only handling. The save dry run returns before the read-only guard (src-tauri/core/src/commands_internal/route_maps.rs:834-837), so the writeback dialog opens, and the write then fails with the generic toast "Trasu a vzdialenosť sa nepodarilo uložiť".
  • A vehicle change in the header does not reload the page: the trip loads once (src/routes/mapa/+page.svelte:849-854). The header selectors look active but have no effect here.
  • The leg buttons of a round trip show no deviation (src/routes/mapa/+page.svelte:1714-1715). The feature doc says each option has its deviation (docs/features/route-maps.md:24-27).
  • Unused i18n key routeMap.notAvailable (src/lib/i18n/sk/index.ts:472), a text for a build without the web server. The app now ships only the web build.
