Kniha jázd on the PC: Fuelio (current state)

The Fuelio cross-check at /fuelio: the GPS drives of the Fuelio app next to the logbook trips, as it works on main. The example data is invented. The UI text is Slovak, as in the app. The notes under each frame say what the screen does.

The source is docs/mockups/fuelio.html in the repo. Its git history shows when the page changed.

An orange dashed box with the tag "Návrh (task NN)" marks a proposal that is not built yet. This page has no open proposal.

Fuelio nie je nastavené. Nastavte premenné prostredia DROPBOX_APP_KEY, DROPBOX_APP_SECRET a DROPBOX_REFRESH_TOKEN.

  • At mount the page calls is_fuelio_available and get_fuelio_filters together. The answer is true only when all three DROPBOX_* env vars are set. A Fuelio folder alone does not count.
  • With the answer false, the page shows only the title, the intro and this red line. The nav has no "Fuelio" link, so the user gets here only by the URL.
  • Without the secrets, the backend refuses every other Fuelio command with an English error ("Dropbox is not configured: ...").
  • Other states of the same place on the page: no active vehicle shows "Vyberte vozidlo.". The first load shows "Načítavam...".
  • If the folder <DATA_DIR>/fuelio does not exist, the info line of frame 2 reads "Priečinok so súbormi Fuelio: /data/fuelio" and, in red, "Priečinok neexistuje. Skopírujte doň zálohu Fuelio (route-*.data)."

  • The page loads the report with get_fuelio_crosscheck for the active vehicle and the selected year. A vehicle or year change loads it again. Only the newest load can set the report.
  • "Jazdy Fuelio v roku 2026: N" counts the drive files of the year in <DATA_DIR>/fuelio. A drive belongs to the local year of the epoch in its file name.
  • "Synchronizovať z Dropboxu (rok)" calls sync_fuelio_dropbox for the selected year. It downloads only the drives that are not in the folder yet, then loads the report again. While it runs, the button is disabled and reads "Synchronizujem...". The result is a toast (frame 8).
  • The server also syncs on its own: at start and then every FUELIO_SYNC_INTERVAL_MINUTES (ADR-061; the default is in the env-var table of CLAUDE.md). The timer syncs the current year, and in January also the last year. The button and the timer never run at the same time.
  • The four inputs come from get_fuelio_filters. With nothing saved, the inputs show the backend defaults (BIZ-027, BIZ-030). A change saves all four with set_fuelio_filters in local.settings.json. An empty input saves as empty.
  • "Min. km" only hides rows below the value (the GPS km, or the book km of a row without GPS). It does not load the report again.
  • The three other inputs go to the backend and load the report again. "Spojiť pri prestávke do (min)" and "a vzdialenosti do (km)" decide when two drives join one row. A drive that belongs to a trip also joins across a longer stop (BIZ-027). "Voľné spárovanie od (% km)" is the share of the trip km that a loose match needs (0 = no minimum). The tooltips are the i18n keys mergeHint and looseMinHint.
  • The pills filter the display only and are not saved. The state pills combine with OR. "Len problémy" and "Len diaľnica" add an AND.
  • With no state pill pressed, the table shows the matched and missing rows. An ignored row shows only under the "Ignorované" pill.
  • "Len problémy" keeps a missing row or a matched row with a warning icon. It never keeps an ignored row. "Len diaľnica" keeps a row with 30 km or more of GPS, or 5 min or more above 100 km/h (tooltip "Jazda >= 30 km alebo >= 5 min nad 100 km/h").
  • "Zobrazené: N" counts the rows after the filters.

  • The frame presses the three state pills, so the ignored row shows too. Row by row: matched clean, loose match, missing, matched with warnings (selected), partial GPS, three drives in one row, ignored.
  • Each row is a run of Fuelio drives. A logbook trip with no drive has no row. The backend sorts the rows newest first by GPS start.
  • The status icon: green check "Spárované", red mark "Chýba v knihe", crossed-out eye "Ignorované". The warning icons follow in the same cell. Each icon has a tooltip with its name.
  • Warnings on a complete match: "Iný čas" if the GPS start is too far from the book start, "Iné km" if the km differ too much, "Iná trasa" if too much of the track is away from the stored route. The thresholds are backend constants (BIZ-027, explained in docs/features/fuelio.md).
  • "Čiastočné GPS": the drives cover only part of a trip with a stored route. Such a row never gets "Iné km". If the run starts mid-trip, it has no minutes, so "Rozdiel" starts with an empty line.
  • "Voľné spárovanie": only the loose pass found the trip (the time and a place or the stored route in common). The row has no other warning and no "mimo trasy" line.
  • "Rozdiel" shows the start difference in min, the km difference in %, and "mimo trasy: N %" when the trip has a stored route.
  • "GPS čas" shows only the times on a matched row, and the full date on a missing row. "(jazdy: N)" marks a row that joins N drives.
  • "Prepísať" on a matched row opens frame 4. A loose row also has "Pridať": a loose match can be another drive. A missing row has "Pridať" (frame 5) and the crossed-out eye "Ignorovať: jazda nepatrí do knihy jázd".
  • The eye calls set_fuelio_drives_ignored for all drives of the row, then loads the report again. An ignored row is grey and has only the open eye "Zrušiť ignorovanie". If a later sync adds a new drive to the run, the row shows again.
  • A click on a row with GPS selects it and draws it on the map (get_fuelio_track): every GPS fix in red, the stored route of the trip in a wider blue line below. The map zooms to both lines.
  • After a load, and when a filter hides the selected row, the first shown row is selected. Before a selection the map is hidden and "Kliknite na riadok so záznamom GPS." shows.
  • Over the map, the panel shows the route of the trip, or the GPS start date for a missing row. A matched trip without a stored route adds "Jazda nemá uloženú trasu.".
  • The map uses Leaflet with OpenStreetMap tiles. The table and the map are side by side only above 1350 px. Below that, the map goes under the table. The table scrolls at 75 % of the screen height.

  • The frame shows a row with "Čiastočné GPS". A row with "Voľné spárovanie" shows "Voľné spárovanie: jazda Fuelio nemusí byť táto jazda." in the same yellow box. The two warnings do not occur on one row.
  • With either warning, all four boxes start empty. On a complete match all four start checked. "Pokračovať" is disabled while no box is checked.
  • Each row shows the book value, then the GPS value. "Začiatok" and "Koniec" write the GPS start and end in whole minutes. "Vzdialenosť" writes the GPS km rounded to whole km.
  • "Trasa" saves the full GPS track as the stored route of the trip (a direct line, no route provider). It replaces the old route.
  • "Pokračovať" first asks for a dry run (apply_fuelio_to_trip, dryRun: true). If "Vzdialenosť" is checked and the rounded GPS km differ from the book km, the dialog changes to "Zápis vzdialenosti trasy" (frame 7). If not, the write runs at once. All checked fields write in one transaction.
  • The backend refuses a new start that moves the trip past another trip, or into another year, and an end before the start. The error shows in red in the dialog, as the English backend text.
  • After the write the dialog closes and the report loads again. The toast says "Jazda bola prepísaná údajmi z Fuelio." or, if no value changed, "Nič sa nezmenilo.". "Zrušiť", Esc or a click outside closes the dialog.

  • The dialog opens from "Pridať" on a missing row or a loose row. It shows "Načítavam..." until get_fuelio_add_preview answers.
  • "Začiatok" and "Koniec" are the GPS start and end in whole minutes. "Vzdialenosť" is the GPS km rounded to whole km. These three are not editable.
  • "Odkiaľ" lists every place with coordinates, nearest to the GPS start first. "Kam" lists them nearest to the GPS end first. The distance shows with 2 decimals below 10 km. The frame draws the open "Kam" list at the right, next to the dialog.
  • The backend preselects a known place near the GPS point (BIZ-031). If no place is that near, the select opens on "+ Nové miesto tu" and shows "Žiadne známe miesto nablízku. ...". "+ Nové miesto tu" is always the first option.
  • "+ Nové miesto tu" shows the input "Názov nového miesta". The new place gets the GPS start point (origin) or the GPS end point (destination). The backend refuses a name that the place book already has, and the same new name on both ends.
  • "Účel" suggests the purposes of the vehicle, as the trip grid does.
  • "Uložiť GPS stopu ako trasu jazdy" (checked at open) saves the full GPS track as the stored route of the new trip.
  • If no place has coordinates, the red line "Žiadne miesto nemá polohu. Doplňte polohu na stránke Miesta." shows under the table.
  • "Pridať jazdu" is disabled until both ends have a place or a new name. It asks for a dry run (add_fuelio_trip, dryRun: true). If later trips move, the insert cascade opens (frame 6). If not, the trip saves at once through the normal insert.

  • The toasts stack top right and close on their own after a few seconds. The frame shows all texts at once.
  • Sync: green with the count of downloaded drives and of drives in Dropbox. If some files fail, the toast is red and adds "Nepodarilo sa stiahnuť: N.". A failed sync shows the error text after the colon.
  • Overwrite: green if a value or the route changed, blue "Nič sa nezmenilo." if not.
  • Add: green, or red if the trip saved but its route did not. The trip stays in the book in both cases, and the dialog closes, so a second click cannot add it again.
  • Other errors of the page (load, ignore, map track, filter save) show the raw error text in a red toast.

Open points (from the code, not fixed)

  • Two code comments say that the Fuelio folder alone turns the page on. The backend needs the three Dropbox secrets (src/lib/api.ts:788, src/routes/+layout.svelte:60 against src-tauri/core/src/server/dispatcher.rs:1061-1062).
  • The dialogs show the backend errors raw, and they are English in the Slovak UI. Example: the order guard "The GPS start would move the trip past another trip; ..." (src-tauri/core/src/commands_internal/fuelio_cmd.rs:308-311, shown by src/lib/components/FuelioOverwriteModal.svelte:168).
  • The page and the dialogs have no read-only handling. The dry runs skip the read-only guard (fuelio_cmd.rs:377-380 for the overwrite, fuelio_cmd.rs:592-594 for the add), so a dialog and the cascade can open, and the final write then fails with an error.
  • The red text "Žiadne miesto nemá polohu. ..." shows when no place has coordinates, but "+ Nové miesto tu" still lets the user add the trip with two new places (src/lib/components/FuelioAddModal.svelte:258-260 against :190-203).
  • A partial-GPS row that starts mid-trip has no minutes value, so the "Rozdiel" cell starts with an empty line (src/routes/fuelio/+page.svelte:511-513).
